# CORE_VISION_RELEASE_GATE_V1
## College Essay Edge

**Purpose:** Nothing ships unless it passes this gate.

---

## 1. Release gate rule

A first-minute change may ship only if it preserves or improves:

- human-feeling guidance
- parent trust
- student clarity
- authenticity safety
- technical cleanliness
- narrative-direction value

If any of these weaken, the change does not ship.

---

## 2. Non-negotiable pass criteria

### A. Human voice
- Output sounds like a thoughtful person, not AI theater
- No canned, abstract, or consultant-like language
- No generic growth/resilience/journey filler

**Pass / Fail**

### B. Calm experience
- No giant reports
- No cluttered screens
- No overwhelming options
- No burden-heavy first-minute behavior

**Pass / Fail**

### C. Story-first behavior
- Product helps find the real story before drafting
- Weak evidence leads to a better question, not more prose
- Direction stays about angle selection, not essay teaching

**Pass / Fail**

### D. Guidance, not ghostwriting
- No full essay production in first-minute flow
- No over-scaffolded writing guidance
- No polished generated openings masquerading as support

**Pass / Fail**

### E. Parent trust
- Clear boundaries
- Clean copy
- Working links
- No malformed rendering
- No fake certainty

**Pass / Fail**

### F. Teen readability
- A student can understand the output immediately
- No jargon, taxonomy, pseudo-intellectual phrasing, or over-academic tone

**Pass / Fail**

### G. Technical cleanliness
- All links work
- All CTAs route correctly
- Session state is preserved
- Add-more-notes continues the same case
- Output validator is active
- Grammar and punctuation are clean

**Pass / Fail**

### H. Clarification quality
- Questions are concrete and case-specific
- Weak answers do not unlock richer output
- Clarification is progressive and non-repetitive

**Pass / Fail**

### I. Reflection discipline
- Reflection remains 2–3 observations only
- No report-writing or analytical sprawl
- Reflection sounds observational

**Pass / Fail**

### J. Direction discipline
- Direction contains only:
  - strongest direction
  - why this beats the obvious version
  - what could make this fall flat
  - best next move
- No extra essay-coaching sections in first-minute flow

**Pass / Fail**

---

## 3. Automatic blockers

If any of these happen, release is blocked automatically:

- broken links
- malformed text rendering
- generic canned clarification questions
- weak evidence producing full confident direction
- essay-coaching scaffolding reappears in first-minute flow
- reflection becomes a report
- output sounds AI-ish or consultant-cheesy
- parent-trust reviewer says “I would not trust this”
- student reviewer says “this feels like another AI tool”

---

## 4. Required sign-off

A release passes only if all three sign off:

### Product
Confirms:
- aligned with Core Vision Charter
- emotionally right
- not drifting into generic AI behavior

### Engineering
Confirms:
- routes and links work
- state management is stable
- validators are active
- no rendering issues

### Founder review
Confirms:
- sounds human
- trusted by parents
- useful for students
- still feels like the original vision

---

## 5. Final release decision

### Ship
All non-negotiables pass.

### Ship with limitations
Only if:
- no blockers
- no Drifted surfaces
- limitations are minor and documented

### Hold
Any non-negotiable fails.

### Reset
If clarification, direction, or technical cleanliness fail in a meaningful way.

---

## 6. One-line release doctrine

**If the product is becoming more impressive-sounding but less trustworthy, less human, or less clear, it is not improving. It is drifting.**
