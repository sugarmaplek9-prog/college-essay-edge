# NDS Proof of Advantage Checklist V1

Date: 2026-04-01

## Purpose

This checklist operationalizes the current founder directive: prove that NDS beats free AI on messy real student input.

Use it to decide whether the next phase is producing founder-reviewable evidence or drifting back into polish.

## Phase checklist

### 1. Input set readiness

- [ ] comparison batch uses real student-note style inputs
- [ ] batch includes messy, mixed-signal, and low-signal cases
- [ ] batch is not limited to showcase strong-input examples
- [ ] case source and provenance are recorded

### 2. Baseline comparison readiness

- [ ] free-AI baseline prompt protocol is documented for the batch
- [ ] baseline outputs are stored alongside NDS outputs
- [ ] comparison artifacts preserve the surfaced recommendation and next move, not just final labels

### 3. Human review readiness

- [ ] batch includes blind or structured human-review packet(s)
- [ ] reviewers can inspect case input, NDS output, baseline output, and outcome labels
- [ ] wins, ties, and losses are annotated with case-level notes

### 4. Failure classification

- [ ] repeated misses are grouped by shared mechanism
- [ ] isolated misses are kept separate from repeated failure classes
- [ ] every proposed remediation is labeled as product-truth, trust, evidence-grounding, or comparative-advantage work
- [ ] Page 3 / Page 4 surface changes are not opened unless a named gate fails or product explicitly approves a narrow correction

### 5. Founder-review packet

- [ ] batch summary states whether the evidence strengthens, weakens, or leaves unresolved the NDS advantage claim
- [ ] summary identifies the strongest current examples of advantage
- [ ] summary identifies the most important unresolved failure class
- [ ] summary states whether engineering time is still concentrated on proof rather than polish

## Exit criteria for this phase

Do not treat this phase as complete unless the evidence packet supports all of the following:

- [ ] strongest-direction choices are repeatedly judged better than free AI on messy input
- [ ] explanations are judged more trustworthy and evidence-anchored than free AI
- [ ] next moves are judged more usable and coach-like than free AI
- [ ] the advantage is visible in more than isolated showcase examples
- [ ] the current failure picture is explicit enough to guide the next serious product correction

## Non-goals during this phase

The following do not count as phase progress by themselves:

- helper-line cleanup
- cosmetic Page 3 / Page 4 refinement
- wording-only rewrites without evidence impact
- broad presentation cleanup without comparative proof value
