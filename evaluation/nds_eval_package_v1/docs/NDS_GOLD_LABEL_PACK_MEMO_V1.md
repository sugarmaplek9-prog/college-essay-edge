# NDS Gold Label Pack Memo V1

This package converts publicly visible college essay guidance requests into a structured NDS adjudication corpus.

## Intended use
- Offline evaluation
- Human adjudication
- Failure clustering
- Benchmark expansion

## Not intended use
- Direct raw-answer training from public forum responses
- Blind trust in public guidance quality

## Current scope
- 25 starter cases
- Mixed difficulty
- Includes core eval cases, hard cases, routing cases, supplement cases, and red-team cases
